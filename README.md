# Sugar 'n Spice Bakery Website

## Project Overview

The Sugar 'n Spice Bakery website was created to provide customers with information about the bakery, its products, prices, contact details and location. The website uses HTML for its page structure, CSS for styling and JavaScript for simple interactive features.

## Website Pages

The website includes the following pages:

- `index.html` – Home page
- `about.html` – Information about the bakery
- `products.html` – Bakery products
- `gallery.html` – A gallery of bakery images
- `price.html` – Product prices
- `contact.html` – Contact information and the bakery's location

## Part 1 – HTML Structure

HTML was used to create the structure and content of the website. The pages include headings, paragraphs, navigation links, images and other relevant content.

### Main features

- Created the main HTML pages for the bakery website.
- Added navigation links so visitors can move between pages.
- Added images to make the website more appealing.
- Created a products page and a price page.
- Created a contact page with the bakery's contact information.
- Started the website afresh and rebuilt the website from the beginning to improve its structure and make the pages more organised.
- Added a separate `gallery.html` page to display bakery images.
- Added a map to the contact page to help visitors find the bakery at **18 Firewood Ave, Hazelwood, Pretoria, South Africa**.
- Added a link for visitors to get directions to the bakery.

## Part 2 – CSS Styling and Responsive Design

### External CSS Stylesheet

An external CSS stylesheet called `style.css` was created and linked to the HTML pages. This helps keep the website's design consistent across the pages.

### CSS Styling

The stylesheet includes styling for:

- Fonts and text sizes
- Text and background colours
- Navigation links
- Borders and spacing
- Buttons
- Hover effects
- Page layout
- Images
- The website footer
- Responsive layouts for different screen sizes

The website uses a pink, cream and brown colour theme to suit the Sugar 'n Spice Bakery brand.

### Responsive Design

Media queries and flexible sizing were used to help the website display on desktop, tablet and mobile screens. Images are styled to fit the available space.

### Website Footer

A footer was added to the website with the bakery name, a short message and links using Facebook, Instagram and Google logos. The links should be updated to the bakery's own social media profiles or business listing when these are available.

## JavaScript

A `script.js` file was added for simple interactive features, such as a welcome message in the browser console, a back-to-top button and basic contact-form validation. The contact form currently demonstrates client-side behaviour only; it does not send messages to a bakery email address or server.

## Testing

The website should be checked in a web browser to confirm that:

- All navigation links open the correct pages.
- Images display correctly.
- The gallery page opens and displays its images.
- The map loads and points to the correct location.
- The directions link opens Google Maps.
- The footer logos and links work.
- The pages remain readable on desktop, tablet and mobile screens.
